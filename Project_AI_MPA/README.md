# Помощник по «1С-Премиум»

Telegram-бот по компании «1С-Премиум» и её услугам премиальной поддержки. Он ведёт диалог с памятью, разбирает голос и фотографии, рисует изображение по явной просьбе и отвечает по материалам сайта через RAG.

Подключение только к официальному OpenAI API: `https://api.openai.com/v1`. ProxyAPI не используется.

## Роль

Основной пользователь — сотрудник или человек, которому нужно быстро ответить про компанию и каталог услуг. Типичные вопросы: чем занимается «1С-Премиум», какая почта для коммерческого предложения, что входит в корпоративную поддержку типовых решений, как устроено внедрение «1С:Шины», зачем компании центр компетенции 1С. База знаний собрана со страниц [о компании](https://www.1c-prem.ru/about/), [каталога услуг](https://www.1c-prem.ru/services/) и [статей](https://www.1c-prem.ru/articles/). Пример запроса в режиме `rag`: «Куда писать за персональным предложением?» — ожидаемый адрес `corp@1c-prem.ru`, источник `company.txt`.

## Возможности

- Текст: GPT-4o и история диалога каждого пользователя
- Голос: Whisper и ответ голосом TTS
- Фото: разбор через GPT-4o Vision
- Генерация: фразы вроде «нарисуй…» уходят в `gpt-image-2`, картинка приходит в чат и остаётся в `data/generated_images/`
- RAG: поиск по `data/documents` в ChromaDB, в ответе указывается файл-источник
- Загрузка txt, md и pdf прямо в чат и команда `/index`

## Запуск

Нужны Python 3.11, FFmpeg и ключи Telegram и OpenAI.

```bash
cd Project_AI_MPA
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python main.py
```

В `.env` заполните `TELEGRAM_BOT_TOKEN` и `OPENAI_API_KEY`. Файл `.env` не коммитится.

На Windows можно запустить `run.bat` после создания `.env`.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | приветствие |
| `/help` | справка |
| `/mode text` | обычный диалог |
| `/mode rag` | ответы по базе знаний |
| `/mode voice` | текстовые ответы ещё и голосом |
| `/mode vision` | подсказка режима разбора изображений |
| `/index` | пересобрать индекс |
| `/stats` | число фрагментов в индексе |
| `/reset` | очистить историю пользователя |
| `/voice nova` | выбрать голос |

Фото можно отправить в любом режиме. Документ txt, md или pdf бот сохраняет в `data/documents` и индексирует.

## Архитектура

```text
Пользователь
  → handlers/[text, voice, image, document_upload, start]
  → services/router.py
  → OpenAI (LLM / Vision / Whisper / TTS / gpt-image-2) + ChromaDB (RAG)
  → ответ в Telegram
```

`handlers` принимает команды и типы сообщений Telegram. `services` ходит в OpenAI и решает, какой это запрос. `rag` загружает файлы, режет их на фрагменты и ищет ближайшие в ChromaDB. `utils` хранит историю диалога, логи и конвертацию аудио. `data/documents` — тексты о компании, услугах и статьях; `data/chroma_db` создаётся при индексации и в git не входит.

Маршрутизация такая: обычный текст идёт в GPT-4o вместе с историей; в режиме `rag` перед моделью выполняется поиск трёх фрагментов; голос сначала становится текстом и проходит тот же маршрут, затем ответ озвучивается; фото уходит в Vision; явная просьба нарисовать картинку уходит в `gpt-image-2`. PNG отправляется в чат и сохраняется в `data/generated_images/`. Эта папка в git не входит.

При старте `main.py` индексирует документы, если состав файлов изменился. Повторный запуск с теми же файлами не дублирует фрагменты. `/index` всегда собирает индекс заново.

## Проверка без Telegram

```bash
python -m compileall .

```

Живые скриншоты `/stats`, RAG, текста, голоса и фото делаются в Telegram после подстановки своих ключей. Голос требует установленный FFmpeg.

## База знаний

Файлы лежат в `data/documents/`. Прежние учебные конспекты удалены.

- `company.txt` — страница «О нас»: компания, принципы, стоимость, контакты и реквизиты
- `service_*.txt` — восемь направлений каталога услуг
- `article_*.txt` — статьи с сайта, включая вайбкодинг, центр компетенции 1С, «1С:Шину», НСИ, мониторинг и информационную безопасность
- `Приглашение_1C_Premium_06_августа.pdf` — документ, добавленный в ту же папку
