# Личный учебный ассистент

Telegram-бот для студента курса по искусственному интеллекту. Он ведёт диалог с памятью, разбирает голос и фотографии, рисует изображение по явной просьбе и отвечает по учебным файлам через RAG.

Подключение только к официальному OpenAI API: `https://api.openai.com/v1`. ProxyAPI не используется.

## Роль

Основной пользователь — студент, который готовит проект мультимодального помощника и параллельно учит материал модуля. Он спрашивает, какая почта учебной поддержки, что сдавать к дедлайну, чем RAG отличается от длинного системного промпта, какие роли есть в учебном Scrum и чем проверить проект перед отправкой в репозиторий. В базе знаний три файла: путеводитель курса, конспект по моделям и RAG, практикум по Python, Scrum и CI/CD. Пример запроса в режиме `rag`: «Какая почта учебной поддержки?» — ожидаемый факт `study@ai-helper.local`, источник `course_guide.txt`.

## Возможности

- Текст: GPT-4o и история диалога каждого пользователя
- Голос: Whisper и ответ голосом TTS
- Фото: разбор через GPT-4o Vision
- Генерация: фразы вроде «нарисуй…» уходят в DALL-E 3, картинка приходит в чат
- RAG: поиск по `data/documents` в ChromaDB, в ответе указывается файл-источник
- Загрузка txt, md и pdf прямо в чат и команда `/index`

## Запуск

Нужны Python 3.11, FFmpeg и ключи Telegram и OpenAI.

```bash
cd Project_AI_MPA
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python main.py
```

В `.env` заполните `TELEGRAM_BOT_TOKEN` и `OPENAI_API_KEY`. Файл `.env` не коммитится.

На Windows можно запустить `run.bat` после создания `.env`.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | приветствие |
| `/help` | справка |
| `/mode text` | обычный диалог |
| `/mode rag` | ответы по базе знаний |
| `/mode voice` | текстовые ответы ещё и голосом |
| `/mode vision` | подсказка режима разбора изображений |
| `/index` | пересобрать индекс |
| `/stats` | число фрагментов в индексе |
| `/reset` | очистить историю пользователя |
| `/voice nova` | выбрать голос |

Фото можно отправить в любом режиме. Документ txt, md или pdf бот сохраняет в `data/documents` и индексирует.

## Архитектура

```text
Пользователь
  → handlers/[text, voice, image, document_upload, start]
  → services/router.py
  → OpenAI (LLM / Vision / Whisper / TTS / DALL-E) + ChromaDB (RAG)
  → ответ в Telegram
```

`handlers` принимает команды и типы сообщений Telegram. `services` ходит в OpenAI и решает, какой это запрос. `rag` загружает файлы, режет их на фрагменты и ищет ближайшие в ChromaDB. `utils` хранит историю диалога, логи и конвертацию аудио. `data/documents` — исходные учебные тексты; `data/chroma_db` создаётся при индексации и в git не входит.

Маршрутизация такая: обычный текст идёт в GPT-4o вместе с историей; в режиме `rag` перед моделью выполняется поиск трёх фрагментов; голос сначала становится текстом и проходит тот же маршрут, затем ответ озвучивается; фото уходит в Vision; явная просьба нарисовать картинку уходит в DALL-E, и файл отправляется в чат.

При старте `main.py` индексирует документы, если состав файлов изменился. Повторный запуск с теми же файлами не дублирует фрагменты. `/index` всегда собирает индекс заново.

## Проверка без Telegram

```bash
python -m compileall .

```

Живые скриншоты `/stats`, RAG, текста, голоса и фото делаются в Telegram после подстановки своих ключей. Голос требует установленный FFmpeg.
