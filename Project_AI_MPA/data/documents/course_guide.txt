Личный учебный ассистент. Путеводитель по курсу

Для кого этот ассистент
Основной пользователь — студент курса по искусственному интеллекту, который собирает личного мультимодального помощника. Ассистент отвечает на вопросы об организации учёбы, требованиях к проекту и о том, как пользоваться самим ботом. Это не справочник компании и не служба техподдержки продукта.

Контакты курса
Электронная почта учебной поддержки: study@ai-helper.local
Канал сдачи: репозиторий проекта и один документ с описанием роли, архитектуры и скриншотами.
Время ответа поддержки: в рабочие дни, в течение одного учебного дня.

Как устроена сдача проекта
Проект сдаётся как Telegram-бот с прямым подключением к OpenAI. ProxyAPI в этом проекте не используется.
В сдаче нужно показать четыре вещи: выбранную роль ассистента, базу знаний, проверку режимов и схему архитектуры.
Обязательные проверки: вопрос в режиме rag с указанием источника, обычный текстовый ответ, голосовое сообщение и анализ изображения.
Дедлайн практического проекта модуля — конец занятия по личному помощнику. Если файл отчёта не приложен, репозитория недостаточно.

Режимы бота
text — обычный диалог с памятью переписки. Модель отвечает как учебный ассистент и не подменяет факты из базы знаний.
voice — ответы дополнительно приходят голосом. Входящее голосовое сначала распознаётся.
vision — пользователь отправляет фотографию, бот описывает её или отвечает на подпись.
rag — ответы берутся из файлов папки data/documents. В ответе нужно название файла-источника.

Команды
/start запускает бота и показывает возможности.
/mode rag включает поиск по учебным материалам.
/mode text возвращает обычный диалог.
/index заново читает файлы из data/documents и пересобирает векторный индекс.
/stats показывает, сколько фрагментов лежит в индексе и где он хранится.
/reset очищает историю диалога конкретного пользователя, но не удаляет базу знаний.
/voice меняет голос синтеза речи: alloy, echo, nova, fable, onyx, shimmer.

Что лежит в базе знаний
course_guide.txt — этот путеводитель: роль ассистента, контакты, режимы и правила сдачи.
ai_study_notes.txt — конспект по мультимодальным моделям и технологии RAG.
dev_practice.txt — практические заметки по Python, Scrum и инструментам CI/CD для учебного проекта.

Как добавить новый материал
Файл в формате txt, md или pdf кладётся в папку data/documents либо отправляется боту документом.
После добавления выполняется команда /index либо бот перезапускается: при изменении файлов индекс собирается заново.
Затем пользователь включает /mode rag и задаёт вопрос своими словами, а не точной цитатой из файла.
