Стек проекта
Бот написан на Python 3.11. Telegram-библиотека — pyTelegramBotAPI в асинхронном режиме.
Ключи читаются из файла .env: TELEGRAM_BOT_TOKEN и OPENAI_API_KEY. Адрес API зафиксирован как https://api.openai.com/v1.
Зависимости ставятся из requirements.txt в виртуальное окружение. Запуск: python main.py из каталога Project_AI_MPA.
Для голосовых сообщений на компьютере нужен FFmpeg: он конвертирует OGG в WAV.
Автотесты лежат в tests и запускаются командой pytest. Внешние вызовы OpenAI в тестах подменяются.

Как вести учебный проект по Scrum
Scrum здесь используется как короткий цикл работы над ботом, а не как процесс большой компании.
Роли на учебном спринте: студент как команда разработки, преподаватель как заказчик продукта, чек-лист занятия как бэклог.
События: планирование в начале занятия, короткий спринт на сборку бота, обзор результата по скриншотам и репозиторию.
Артефакты: бэклог требований из задания, список файлов базы знаний и работающий бот как инкремент.
Длина учебного спринта совпадает с занятием. В бэклог не добавляются оплата, авторизация пользователей и веб-интерфейс: для сдачи достаточно Telegram.

Инструменты CI/CD, которые уместны для этого репозитория
Проверка перед отправкой: pytest запускает модульные тесты без реальных ключей.
GitHub Actions подходит как первый шаг непрерывной интеграции: на push ставить зависимости и выполнять pytest.
Ruff или встроенная проверка синтаксиса python -m compileall ловит опечатки до запуска бота.
Docker имеет смысл позже, если бота нужно поднять на сервере вместе с FFmpeg. Для локальной сдачи контейнер не обязателен.
Непрерывная доставка в этом задании — это push в личный репозиторий, а не выкладка на продакшен-сервер.

Повседневные команды разработки
Создать окружение: python -m venv venv, затем venv\Scripts\activate на Windows.
Поставить пакеты: pip install -r requirements.txt.
Скопировать .env.example в .env и вписать свои ключи. Файл .env не коммитится.
Проверить код без запуска бота: python -m compileall .
Запустить бота: python main.py. Остановить: Ctrl+C.
Пересобрать базу после правки конспектов: команда /index в Telegram.

Что считать готовностью
Бот отвечает в режиме text и помнит предыдущий вопрос в рамках истории.
В режиме rag ответ опирается на один из трёх файлов и называет его.
Голосовое сообщение возвращает распознанный текст и голосовой ответ.
Фотография получает текстовый разбор.
Запрос «нарисуй…» приводит к изображению в чате.
В репозитории есть README с ролью ассистента, запуском и схемой папок.
